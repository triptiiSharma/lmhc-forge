# Figures Manifest

Generated by `src/visualize.py` using the shared five-color palette in
`src/style.py` (Wasabi / Orange Topaze / Cool Blue / Cassis / Vert Sauge —
see that file's docstring for the reserved role of each color). Every figure
is written as both a 300-dpi PNG and a vector PDF. Regenerate all of them
with:

```bash
python3 src/visualize.py
```

The "Paper section" column is a reference mapping only (Phase 3.5 of the
build plan) — it does not imply any figure has been placed into
`docs/LMHC_v2.docx`; that file is untouched by this tooling.

## Accessibility

`fig3_exposure_index`, `fig5_tamper_panel`, `fig1_phase0_heatmap`,
`fig10_multi_gpu_comparison`, and `fig11_three_path_comparison` all use the
Orange Topaze / Vert Sauge pairing (indistinguishable under red-green color
vision deficiency) and each redundantly encodes the same distinction via
hatching, a ✓/✗ icon, or an explicit text label — see `pass_fail_kwargs()` /
`pass_fail_label()` in `src/style.py`.
